# SHIT GINJA 👠

**Backwards and in high heels.**

A deliberately tiny subtractive printmaking toy in the Shit Suite.

- one palette: Sturdy
- three V-shaped gouges
- undo, because we're not monsters
- no dots, stripes, stamps, or shortcuts
- carve the block, then print it
- the print is mirrored, because printmaking

Every mark is made by hand.
